# Допуск записи и оплаты услуг

Маршрут доступен в тестовой организации. Для работы настройте услугу и выделенный ресурс сотрудника вместимостью 1, задайте часы бизнеса, услуги и смены, затем пригласите сотрудника с правом на заявки. При первом назначении владелец закрепляет ресурс за сотрудником. Для смены исполнителя в уже назначенной записи владелец отменяет её и создаёт новую. Исполнитель завершает услугу после окончания слота. Владелец вручную записывает фактическое поступление и себестоимость, включая явно введённый ноль для услуги без себестоимости. Финансовый итог охватывает учтённые оплаты. Finance и Analytics получают эти же данные в существующих заданиях на чтение.

Для реальной организации требуется отдельный релиз с явно заданным допуском на уровне организации. Сохранить проверку членства, ограничения операторов, FORCE RLS, согласования, коммерческие лимиты и отключённую внешнюю отправку. Перед допуском проверить на отдельной организации отзыв роли, параллельное бронирование, повтор записи оплаты, восстановление из свежей копии и действующий допуск релиза. Откат миграции 39 разрешён при пустых новых таблицах. С фактическими операциями нужен согласованный сценарий восстановления с сохранением записей и финансов.
